CROP RECOMMENDATION PROJECT - CODE EXPLANATION
==============================================
The code files have no comments. This file explains them.
Line numbers refer to the lines in each file.


--------------------------------------------------
train.py  (trains the models and saves the best one)
--------------------------------------------------
Lines 1-12   Import the libraries we need.
             pandas handles the data, joblib saves the model, matplotlib draws charts,
             scikit-learn gives us the models and the testing tools.

Line 14      Read the dataset from the CSV file into a table (DataFrame).
Line 15      Print the number of rows and columns (2200 rows, 8 columns).
Line 16      Print the total missing values (it is 0, so no cleaning is needed).

Line 18      X = all input columns (N, P, K, temperature, humidity, ph, rainfall).
Line 19      y = the answer we want to predict (the crop name).

Lines 21-23  Split the data into a training part and a testing part.
             test_size=0.2    -> 20% is kept for testing, 80% is used for training.
             random_state=42  -> the split is the same every time the code runs.
             stratify=y       -> every crop appears equally in both parts.

Lines 25-30  Make the four models we want to compare.
             Logistic Regression -> a simple model that draws straight boundaries between
                                    crops. It is our baseline (the simple model to beat).
                                    StandardScaler puts all features on the same scale first.
             Decision Tree       -> asks a series of yes/no questions, like a flowchart.
             Random Forest       -> 100 decision trees that vote together.
             KNN                 -> looks at the 5 most similar rows and copies their crop.

Lines 32-35  Empty variables to remember the best model while we check each one.

Line 37      Go through the four models one by one.
Line 38      Cross-validation: the training data is split into 5 parts. The model is
             trained on 4 parts and tested on the 5th, five times, and we take the
             average. This shows the result is not just luck from one split.
Line 39      fit() trains the model on the training data. This is where it learns.
Line 40      predict() guesses the crops for the test data the model has not seen,
             and accuracy_score gives the percentage that were correct.
Line 41      Print the test accuracy and the cross-validation accuracy.
Lines 42-46  Save these numbers as one row of the results table.

Lines 48-51  If this model scored higher than the best so far, remember it as the best.

Line 53      Turn the rows into a table, sorted from the best model to the worst.
Line 54      Print the name of the best model (Random Forest).

Line 56      Get the best model's predictions on the test data.
Line 57      Print precision, recall and F1-score for each crop.

Line 59      Create the "charts" folder if it does not exist.

Lines 61-68  Draw the confusion matrix and save it as charts/confusion_matrix.png.
             Rows are the real crops, columns are the predicted crops. The diagonal
             shows correct predictions. Numbers outside the diagonal are mistakes
             (for example, one blackgram was predicted as maize).

Lines 70-76  Draw the feature importance chart and save it as charts/feature_importance.png.
             It shows which inputs helped the Random Forest most (rainfall, humidity and
             potassium are the top three).

Lines 78-83  Put the best model, its name, its accuracy and the results table in one dictionary.
Line 84      Save that dictionary into model.pkl so the app can use it without training again.
Line 85      Print a message that saving is done.


--------------------------------------------------
app.py  (the Streamlit web page)
--------------------------------------------------
Lines 1-3    Import the libraries. streamlit builds the web page.

Line 5       Set the browser tab title and icon.

Line 7       Load the saved file model.pkl.
Line 8       Take the trained model out of it.

Line 10      Show the big title on the page.
Line 11      Show a short instruction line.

Line 13      Make two columns so the input boxes sit side by side.

Lines 15-19  Left column: input boxes for N, P, K and temperature.
             The three numbers in each box are: minimum, maximum, default value.
Lines 21-24  Right column: input boxes for humidity, pH and rainfall.

Line 26      Create the Predict Crop button. The code below runs only when it is clicked.
Lines 27-30  Put the entered values into a one-row table.
             The column names must be the same as the ones used in training.

Line 32      The model predicts the best crop for these values.
Line 33      Show the crop name in a green box (title() makes the first letter capital).

Line 35      predict_proba gives the model's confidence (probability) for every crop.
Line 36      Join each crop with its probability, sort from highest to lowest,
             and keep the top 3.
Lines 37-39  Show the top 3 crops with their percentages.

Lines 41-46  A collapsed section "About the model" that shows the best model and its
             accuracy, the comparison table, the two charts, and a short limitation note.


--------------------------------------------------
crop_analysis.ipynb  (data analysis notebook)
--------------------------------------------------
The notebook code has no comments. Each section has a heading and a short
explanation above its code cell. In order:

1. Load the data
2. Basic information (rows, missing values, duplicates, number of crops)
3. Rows per crop (100 each, so the data is balanced)
4. Histograms of all 7 features
5. Correlation heatmap (only P and K are strongly related, about 0.74)
6. Average values of each feature for every crop
7. Rainfall by crop boxplot (rice needs the most rain)
8. Temperature vs humidity scatter plot
9. Feature importance (rainfall, humidity and potassium matter most)
Conclusion

Other files
--------------------------------------------------

charts/                   The confusion matrix and feature importance images, created by train.py.
requirements.txt          The libraries to install with: pip install -r requirements.txt
README.md                 A short description of the project and how to run it.


--------------------------------------------------
How to run
--------------------------------------------------
1. pip install -r requirements.txt
2. python train.py           (creates model.pkl and the charts)
3. streamlit run app.py      (opens the web app)
4. jupyter notebook          (open crop_analysis.ipynb for the analysis)
